# albertsein.com

Personal site for **Albert Sein** — materials & systems engineer at UVA, founder of Ordo.

A single self-contained static page. No build step, no dependencies (system fonts, inline CSS/JS).

- `index.html` — the whole site
- `albert-sein-resume.pdf` — résumé, linked from the contact section

## Deploy

Static hosting. On Vercel: import the repo → Framework preset **Other** → no build command → output directory = repo root. Then add the custom domain `albertsein.com`.
